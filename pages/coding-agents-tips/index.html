GOAL: Continuous Curiosity

AI coding tools are powerful — but how you use them determines whether you're building skills or outsourcing them.

Recent research from Anthropic studied how different modes of AI interaction affect skill development. 

Turns out: 
People who simply delegated tasks to AI ("just generate the code") scored lowest on skill assessments after completing a coding task — even though they did the task just fine.
Those who practiced continuous curiosity — asking the AI to explain, questioning its choices, and understanding before moving on — developed significantly stronger skills in the same amount of time.

You can use AI and not learn anything, or you can use it and learn more than you would have doing in manually. 

This guide is designed around this principle. You'll configure Claude Code to act as a mentor that explains concepts as it writes code — and you'll build the habit of asking "why?" at every step.

📌If you don't have a good terminal app for claude, consider: cmux, Ghostty, Kitty, or Warp.

What is Claude Code?

Claude Code is an agentic coding tool that runs in your terminal. Unlike the web chat interface, Claude Code can read and edit files in your project, run commands, and help you build things directly in your codebase.

Here's what it looks like when you run claude in a project directory:

You type prompts, Claude responds, and it can edit your files directly. Think of it as pair programming with an AI partner.

To Start

Create a CLAUDE.md file in your project directory (or an empty folder if you are just starting out) with the following contents:

markdown
12345678910111213141516171819202122
# Learning Agent Configuration

You are a patient mentor helping someone learn to code. Your goal is to explain and teach concepts and mental models, not just produce working code.

## Teaching Approach
- Ask the user if they would like you to edit files directly or if they would like to type in the code themselves
- Break problems into conceptual blocks — don't do too much in each step
- Before writing code, explain the concept
- Explain the code before you write it to a file
- After writing code, ask "Does this make sense?" before continuing
- If they seem confused, slow down and re-explain
- Keep edits short; split them into multiple steps with explanations at each step

## Problem Decomposition
- Start with the structure/skeleton before adding details
- Identify the core pieces: data, presentation, interaction
- Work through one piece at a time
- Connect concepts to things the learner already knows

## Pacing
- Build in functional increments
- Focus on understanding over complexity
- Celebrate small wins along the way

Setup Claude Code

Follow these steps to get set up:

  1. Install Claude Code CLI:
Terminal
curl -fsSL https://claude.ai/install.sh | bash

Or download here

  1. Authenticate by running claude and following the prompts.  (you may have a Claude console account from CS52/CS98 otherwise you'll need a claude.ai subscription). 

Setup Chrome Integration

⚠️This step is really important for web-dev in particular! Chrome integration lets Claude open and test your code in the browser as it builds.  It closes the loop so you don't have to tell it that its code didn't work, it can see for itself.  A common prompt I use: "test this in browser and debug until it works". 

There are two options for Chrome integration:

Option A: Claude in Chrome (Recommended)

This option requires an individual claude.ai Pro/Max subscription. If you're using a Claude Console API account, skip to Option B.

Claude in Chrome is a browser extension that lets Claude Code control Chrome directly:

  1. Install the extension from the Chrome Web Store
  2. Add the MCP server to Claude Code:
Terminal
claude mcp add claude-in-chrome --scope user -- npx -y claude-in-chrome-mcp@latest
  1. Restart Claude Code to load the new server
  2. Test it by asking Claude to open a browser and navigate to a website

Option B: Chrome DevTools MCP

If you're using a Claude Console API account, use the Chrome DevTools MCP server instead:

  1. Add the MCP server to Claude Code:
Terminal
claude mcp add chrome-devtools --scope user -- npx chrome-devtools-mcp@latest
  1. Restart Claude Code to load the new server
  2. Test it by asking Claude to open a browser and navigate to a website

Part 1: Review Your Learning Agent Config

Check out the CLAUDE.md file from above. This is a special file that Claude reads at the start of every conversation — it's like giving Claude instructions about how to work with you.

Open it and take a look. It tells Claude to:

  • Break problems into conceptual blocks
  • Explain concepts before writing code
  • Focus on teaching, not just producing code
  • Check in to make sure you understand
💬Feel free to customize the CLAUDE.md! Want Claude to be more concise? Add that. Prefer more examples? Tell it. This is your learning agent.

Once you start working on your project you should also keep very succinct details about your project in this file.  How to run it,  does it have a database, how to test, where to put shared code and abstractions to use. 

Part 2: Start Building with Claude

Now for the fun part! Open Claude Code in your terminal from your project.

Terminal
cd your-project
claude

Try prompts like these to get started. Claude will build with you while explaining each concept:

Start Simple

💬"i want to build [idea].  walk me through planning it step by step and explain each concept as you go."

Understand What You Built

💬"explain how [specific part] works. i want to understand it, not just have working code."

Add Features Incrementally

💬"now let's add [feature]. before you write code, explain the approach you'd take."

Debug Together

💬"this isn't working: [paste error message or describe issue]. help me understand what's wrong."

Tips for Working with Claude Code

Essential Commands

CommandWhat it does
/planHave Claude plan before coding — great for understanding the approach first
/compactSummarize the conversation when context gets long
/clearStart fresh when switching to a different task
EscapeCancel Claude mid-response if it's going the wrong direction

Use Plan Mode — Seriously

This is the most important habit to build.

When you give Claude a task, it wants to start coding immediately. That's often a mistake. Plan mode (/plan) forces Claude to think through the approach first:

  • You see the strategy before any code is written - Catch bad approaches early, not after 500 lines of code.
  • You can ask questions about the plan - "Why this library?" or "What about edge case X?"
  • You learn how to break down problems - Watching Claude decompose a task teaches you to think the same way.
  • You stay in control - Approve each phase before Claude moves on.

Without plan mode, Claude might build something that technically works but uses the wrong approach, wrong libraries, or wrong architecture. 

💬Try: "let's plan this out before writing any code. what are the main pieces we need to build?"

Plan mode uses exploration subagents and it does a great job figuring out where in the project you already are.

Effective Prompting

  • Paste error messages directly - Claude reads stack traces well. Copy the whole thing.
  • Share screenshots - Claude can see images. Great for debugging UI issues. Just paste in.
  • Be specific - "Fix the bug" is vague. "The button click handler isn't firing" is actionable.
  • Ask for explanations - If Claude writes something you don't understand, stop and ask. That's the whole point.

Project Workflow

  • Claude can use git - Ask it to commit changes, create branches, even open PRs.
  • Review diffs before accepting - Claude shows you what it's about to change. Read it.
  • Start new conversations - When switching tasks, use /clear. Old context can confuse things.
  • Use CLAUDE.md for memory - Want Claude to remember something? Ask it to add notes to CLAUDE.md.

Efficiency Tips

  • Keep CLAUDE.md focused - Bloated instructions waste tokens every conversation.
  • Test in browser - If you set up Chrome integration, ask Claude to open your page and test it.
  • Let Claude search the web - It can look up current docs, APIs, and solutions.

By working with Claude Code, you should get comfortable with:
